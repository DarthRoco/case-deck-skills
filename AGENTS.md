# AGENTS

Before building any PPTX in this repo, pick a skill and read it.

- Dense case-competition cards → `skills/case-like-deck-maker/SKILL.md`
- Sparse exhibit-led readout → `skills/exhibit-readout-deck-maker/SKILL.md`

Follow the skill. Do not invent a third visual system.
Copy helpers + token-block into the generation script. Do not rewrite chrome.
Run the matching `scripts/density-critic.py` before claiming done.

Use only marks the user supplied. Set `footerName` to the client or to
`Prepared for the working session`. Flag invented numbers as assumptions.
