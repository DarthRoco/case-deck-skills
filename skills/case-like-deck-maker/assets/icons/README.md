# Icons

This folder is optional.

Drop square PNG files here if you want icons on dense case-comp cards.
The helper looks up a file by stem:

- `market.png` → `H.icon(slide, "market", x, y)`
- `handshake.png` → `H.icon(slide, "handshake", x, y)`

Suggested size: 128×128, monoline, transparent background, one weight.

If this folder has no `.png` files, the skill must not invent clip-art or
emoji. Use numbered geometric markers instead (1 / 2 / 3 in circles).

Only drop marks you have a licence to use.
