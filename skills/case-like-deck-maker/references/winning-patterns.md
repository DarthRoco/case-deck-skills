# Working patterns

Drafting rules for dense case-competition decks.

## What a working slide feels like

A judge can screenshot one content slide and still reconstruct the argument. That means

- insight title (the so-what)
- 3–7 modules (cards, table, mini-chart, quote, hero number)
- one persistent navigator so they know where they are
- a source crumb

## Recurring modules that earn their keep

| Module | When to use |
|---|---|
| Situation / Problem / Answer strip | Slide 2 |
| SWOT four-tile | Company entry |
| Competitor 2×2 | Crowded industry |
| Attractiveness / feasibility table + RAG | Ranking options |
| Named-idea banner | Recommendation |
| Current vs proposed table | Product / ops change |
| Journey with the broken step boxed | Consumer / user cases |
| Persona card (photo, sliders, quote, needs/pains) | Any human-facing case |
| Phone / UI flow | Product features |
| Cost vs benefit footer | Product ideas |
| Financial trio (assumptions, P&L, chart + insights box) | Any commercial case |
| Unit economics + policy pack | Infra / public-private |
| Phase chevron or year-column roadmap | Implementation |
| Campaign 360 + ROI | Marketing cases |
| Conclusion as 3 pillars with reused metrics | Last content slide |
| Stakeholder quote row | Appendix or proof |
| Survey pies that feed the next action | Awareness / GTM |

## Naming patterns that stick

- Merged entity name
- Feature named as a product
- Character / agent name for a service layer
- Campaign line in the local language
- Program codename

Give the recommendation a name on the spine, then print that name on every later slide that executes it.

## Research staging

Minimum viable primary-research module

- n = (surveys / interviews / groups) stated once on the first research slide
- 2–4 hero percentages with the question paraphrased
- 1–3 named voices (first name or role + city + one sentence)
- Personas only if the case is human-facing; cap at 3

Do not invent interview names that sound like film characters unless the user already did — and label those as personas, not as field interviews.

## Density that still reads

These decks are dense. They stay readable because of

- cards with header bars instead of walls of 9 pt text
- consistent column edges
- one accent colour plus RAG
- footer reserved for navigator + sources, never a seventh content row

If a draft slide has a paragraph longer than 30 words, split it into a card heading + two fragments.

## Annexure hygiene

Main deck argues. Annexure proves.

Put in annexure: extra survey charts with a one-line CONCLUSION box under each, storyboard frames, detailed Gantt, channel-wise cost build-up, interview transcripts, model metrics, working-file links.

Divider slide uses the same cover texture so the dump still feels on-brand.
