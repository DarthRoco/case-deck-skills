# Working patterns

Drafting rules for exhibit-led readouts.

## What a partner-ready slide feels like

A partner can read only the titles and reconstruct the memo. That means

- action title (the so-what as a sentence)
- one exhibit (chart, waterfall, table, or conceptual diagram)
- optional 3–5 bullet rail
- SOURCE + identity footer
- no second story

## Recurring modules that earn their keep

| Module | When to use |
|---|---|
| Agenda / contents contract | Slide 2 |
| Governing situation chart | Early |
| Bridge / waterfall | What moved the number |
| Distribution curve | Why the average is a trap |
| Method table | Public / messy stakeholder cases |
| Scope box | When the room will attack boundaries |
| Choice split | Recommendation |
| Named framework | Only if it carries the choice |
| Snapshot triad | Thought-leadership cover-after-cover |
| Exhibit N \| claim | White-paper pages |
| Pyramid + two pillars | Purpose / operating model |
| Decision frame / next 90 days | Close |
| Confidential line | Footer or title verso |

## Naming patterns that stick

- Programme names — Operational Excellence, Full Potential, All-in
- Object names — challengers, five levers, power curve, Engine 1 / Engine 2
- Choice names — Actions within control vs Structural change
- Document type — Discussion document, WHITE PAPER, PRELIMINARY, Presentation of findings

Give the recommendation a name on the spine and print that name on every later slide that executes it.

## Research staging

Minimum viable proof module

- n + window + universe on the exhibit (n = 2,393 firms, 2010–14)
- method slide when primary work is the credibility
- SOURCE on the slide, never only at the back
- definitions as numbered notes (`1 Live-release rate from shelter`)

Do not invent interview names. Do not dress a desk-research slide up as ethnography.

## Density that still reads

These decks are quieter than campus comps. They stay readable because of

- one idea per slide
- action titles
- tinted exhibit wells instead of eight cards
- one chromatic family colour plus grey
- footer reserved for SOURCE + identity

If a draft slide has two charts, split it. If a paragraph is longer than 40 words on a working slide, it belongs on a commentary page or in the appendix.

## Annexure hygiene

Main deck argues. Appendix proves.

Put in appendix: extra cuts, full survey tables, interview lists, model workings, legal memos, long attachment packs.

Divider slide uses the same footer identity so the dump still feels on-brand.
